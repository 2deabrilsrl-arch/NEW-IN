CAMBIOS TÉCNICOS DETALLADOS (PARA REFERENCIA)
==========================================================================

La nueva versión v12.0.0-MADRE cambia la lógica fundamental de matching:

ANTES (v11.3.0):
  1. Dragonfish: "T-1100#231#90"
  2. Buscar en TN: ¿Existe variante con SKU exacto "T-1100#231#90"?
  3. Si NO existe ese talle específico → NO MATCH
  4. Resultado: Match rate 6%

DESPUÉS (v12.0.0):
  1. Dragonfish: "T-1100#231#90"
  2. Extraer código madre: "T-1100"
  3. Buscar en TN: ¿Existe ALGUNA variante con "T-1100"?
  4. Si existe el producto T-1100 (aunque con otros talles) → MATCH
  5. Agregar producto COMPLETO a New In
  6. Evitar duplicados automáticamente
  7. Resultado: Match rate esperado 80%+

Funciones modificadas:
  - Nueva: extract_madre_code() - Extrae código antes del primer #
  - Nueva: tn_build_madre_index() - Indexa por código madre
  - Modificada: daily_update() - Usa matching por código madre
